# Интерактивный дашборд для анализа телеметрии нефтегазовых скважин

## 📌 Описание проекта

Дашборд предназначен для визуализации и анализа данных телеметрии нефтегазовых скважин.  
Позволяет в интерактивном режиме строить 4 типа графиков, фильтровать данные по скважине, изменять масштаб и тип агрегации.

**Вариант задания:** №14 — Геологические скважины (давление, температура, вибрация, состав флюида)

---

## 🚀 Возможности

- **4 типа графиков:**
  - Линейный (динамика добычи по времени)
  - Столбчатый (сравнение по сезонам или уровню риска)
  - Точечный (зависимость между параметрами)
  - Тепловая карта (скважины × сезоны)

- **Динамические настройки:**
  - Выбор скважины
  - Тип агрегации (сумма / среднее / медиана)
  - Масштаб времени (день / месяц / год) — для линейного графика
  - Группировка (сезон / риск) — для столбчатого
  - Оси X, Y и цветовая кодировка (риск / сезон) — для точечного
  - Параметр отображения (v_oil / press / temp / vib) — для тепловой карты

- **Предобработка данных:**
  - Удаление некорректных записей (NaN, Inf)
  - Обрезка выбросов по IQR с заменой на медиану
  - Создание производных признаков (сезон, объём нефти, уровень риска)

- **Экспорт графиков** в PNG или PDF
